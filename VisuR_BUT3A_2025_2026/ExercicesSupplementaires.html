– Manipulation des données –

En utilisant le jeu de données hdv2003, écrire dans un script les commandes qui permettent de répondre aux questions suivantes :

1. Quel est le nombre moyen de frères et soeurs des individus ?
On souhaite calculer cet indicateur sur l’ensemble de l’échantillon et pour chaque modalité de la pratique de la religion.

2. Quel est le nombre maximum d’heures passées devant la TV pour les individus qui sont à la retraite ?
On veut que le résultat affiche l’identifiant de ces individus, leur occupation antérieure et le nombre d’heures passées devant la TV*.

3. Quel est le nombre total d’heures passées devant la TV par les étudiants/élèves ?

4. Quelles sont les valeurs minimales, médianes et maximales du nombre d’heures passées devant la TV par classe d’âge ?
On souhaite découper selon les classes d’âges suivantes : 18-24 ; 25-39 ; 40-54 ; 55-64 ; 65+.
La nouvelle variable “cl_age” doit être placée après la variable “age” dans un nouveau jeu de données qui s’appellera hdv2003_m.

Première étape : chargement des packages et des données

# Chargement des packages
library(dplyr)    # v1.1.4
library(tidyr)    # v1.3.1
library(ggplot2)  # v3.5.2
library(viridis)  # v0.6.5 # pour palette couleurs

# Chargement des données
data(hdv2003)

Question 1. Nombre moyen de frères et soeurs

# Pour l'ensemble des individus
hdv2003 |> 
  summarise(FreresSoeurs_moyenne = mean(freres.soeurs, na.rm = TRUE))

hdv2003 |>

  summarise(FreresSoeurs_moyenne = mean(freres.soeurs, na.rm = TRUE))

Question 4. Ajout de la variable “cl_age” dans un nouveau jeu de données nommé hdv2003_m et calcul des indicateurs par classes d’âge

# Création de la variable cl_age
hdv2003 |> 
  mutate(cl_age = ifelse(age  >= 18 & age <= 24, "18-24", 
                         ifelse(age  >= 25 & age <= 39, "25-39",
                                ifelse(age  >= 40 & age <= 54, "40-54",
                                       ifelse(age  >= 55 & age <= 64, "55-64",
                                              ifelse(age >= 65, "65+", "ERREUR")))))) |> 
  relocate(cl_age, .after = age) -> hdv2003_m

# On obtient le même résultat en écrivant les commandes suivantes 
hdv2003 |> 
  mutate(cl_age = case_when(age  >= 18 & age <= 24 ~ "18-24",
                            age  >= 25 & age <= 39 ~ "25-39",
                            age  >= 40 & age <= 54 ~ "40-54",
                            age  >= 55 & age <= 64 ~ "55-64",
                            age >= 65 ~ "65+",
                            TRUE ~ "ERREUR")) |> 
  relocate(cl_age, .before = sexe)  -> hdv2003_m

# Indicateurs du nombre d'heures passées devant la TV par classe d'âge
hdv2003_m |> 
  group_by(cl_age) |> 
  summarise(Min = min(heures.tv, na.rm = TRUE), 
            Mediane = median(heures.tv, na.rm = TRUE),
            Max = max(heures.tv, na.rm = TRUE))

– Représentations graphiques avec {ggplot2} –

On utilise pour cet exercice le jeu de données hdv2003_m auquel on va supprimer les observations qui ont une valeur manquante à la variable “heures.tv”. Le nouveau jeu de données s’appellera hdv2003_TVnarm.

1. Représenter la distribution du nombre d’heures passées devant la TV en fonction de l’âge, sous forme de nuage de points.

2. Représenter la distribution du nombre d’heures passées devant la TV en fonction des classes d’âge, sous forme de boxplot.
Les boxplot auront une couleur différente selon les classes d’âge.
On utilisera une palette de couleurs adaptée aux variables catégorielles.

3. Représenter la distribution de la variable de satisfaction au travail, en excluant les non réponses à cette variable

  1. pour faire une analyse globale
  2. pour faire une analyse selon les classes d’âge, avec des barres de couleurs différentes selon la satisfaction au travail

Pour ces 2 graphiques, les modalités de la variable de satisfaction doivent être ordonnées : insatisfaction, équilibre, satisfaction.

4. Refaire le graphique 3b, en ne retenant que les individus pour lesquels le travail est aussi important que le reste.
Sur ce graphique, on veut représenter les pourcentages et non pas les effectifs.

Les graphiques doivent comporter les informations nécessaires à leur bonne compréhension : titres, labels, etc.

Étape préliminaire : suppression des observations pour lesquelles la valeur de “heures.tv” est manquante

hdv2003_m |> 
  drop_na(heures.tv) -> hdv2003_TVnarm

Question 1. Nuage de points

ggplot(data = hdv2003_TVnarm) + 
  geom_point(aes(x = age, y = heures.tv)) +
  # informations
  labs(x = "Age", 
       y = "Heures TV",
       title = "Distribution du nombre d'heures passées devant la TV \n en fonction de l'âge.")

Question 2. Boxplot

ggplot(data = hdv2003_TVnarm) + 
  aes(x = cl_age, y = heures.tv, fill = cl_age) +
  geom_boxplot() +
# palette couleurs Viridis
  viridis::scale_fill_viridis(discrete = TRUE) +
  # informations
  labs(x = "Age", 
       y = "Heures TV",
       title = "Distribution du nombre d'heures passées devant la TV \n en fonction des classes d'âge.")

Question 3. Barplot

Préparation des données : suppression des données manquantes à “trav.satisf” et ordre des modalités
hdv2003_TVnarm |> 
  # suppression des valeurs manquantes
  drop_na(trav.satisf) |> 
  # ordre des modalités
  mutate(trav.satisfOrdonne = factor(trav.satisf, 
                              levels = c("Insatisfaction", "Equilibre", "Satisfaction"))) |> 
  relocate(trav.satisfOrdonne, .after = trav.satisf) -> hdv2003_TravSatisfnarm
Analyse globale
ggplot(data = hdv2003_TravSatisfnarm) + 
  aes(x = trav.satisfOrdonne) +
  geom_bar() +
  # informations
  labs(x = "Satisfaction au travail", 
       y = "Effectif",
       title = "Distribution de la variable de satisfaction au travail.")
Analyse selon les classes d’âge
ggplot(data = hdv2003_TravSatisfnarm) + 
  aes(x = trav.satisfOrdonne, fill = trav.satisfOrdonne) +
  geom_bar() +
  # graphique pour chaque modalité de cl_age
  facet_grid(cols = vars(cl_age)) +
  # choix des couleurs
  scale_fill_manual(values = c("#D55E00", "#BDBDBD", "#009E73"),
                    # modification du titre de la légende
                    name = "Degré de satisfaction") + 
  # informations
  labs(x = NULL, 
       y = "Effectif",
       title = "Distribution de la variable de satisfaction au travail \n selon les classes d'âge.") +
  # améliorations visuelles
  theme(axis.text.x = element_blank(), # suppression des étiquettes de l'axe des abscisses
        legend.position = "bottom")    # positionnement de la légende sous le graphique

Question 4.

# Préparation des données
hdv2003_TravSatisfnarm |> 
  # sélection des individus pour lesquels le travail est aussi important que le reste
  filter(trav.imp == "Aussi important que le reste") |> 
  # sélection des variables à représenter sur le graphique
  select(cl_age, trav.satisfOrdonne) |> 
  # calcul des pourcentages des modalités de trav.imp pour chaque classe d'âge
  tidyr::pivot_longer(cols = trav.satisfOrdonne,
                      names_to = "satisfaction",
                      values_to = "degre") |> 
  # groupes par classes d'âge
  group_by(cl_age) |> 
  # calcul des effectifs de chaque degré de satisfaction par classe d'âge
  dplyr::count(degre) |> 
  # calcul des pourcentages de chaque degré de satisfaction par classe d'âge
  dplyr::mutate(pourcentage = n / sum(n) * 100) |> 
# Graphique à partir des données préparées au-dessus
ggplot() + 
  aes(x = degre, y = pourcentage, fill = degre) +
  geom_bar(stat = "identity") + # stat = "identity" car y précisé dans aes()
  # graphique pour chaque modalité de cl_age
  facet_grid(cols = vars(cl_age)) +
  # choix des couleurs
  scale_fill_manual(values = c("#D55E00", "#BDBDBD", "#009E73"),
                    # modification du titre de la légende
                    name = "Degré de satisfaction") + 
  # graduations de l'axe des ordonnées
  scale_y_continuous(limits = c(0, 100),   # valeurs min et max de l'axe
                     breaks = seq(from = 0, to = 100, by = 20)) +  # graduations
  # informations
  labs(x = NULL, 
       y = "Pourcentage",
       title = "Distribution de la variable de satisfaction au travail \n selon les classes d'âge.",
       caption = "Uniquement pour les individus pour lesquels 
                 le travail est aussi important que le reste") +
  # améliorations visuelles
  theme(axis.text.x = element_blank(), # suppression des étiquettes de l'axe des abscisses
        legend.position = "bottom")    # positionnement de la légende sous le graphique
