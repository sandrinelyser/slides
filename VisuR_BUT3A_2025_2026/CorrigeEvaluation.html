Rappel des consignes et données

À partir du jeu de données films vous devez effectuer une analyse reproductible et répondre aux trois questions qui vous sont posées.

Vous écrirez les commandes et les réponses aux questions dans un script R.

Le jeu de données films

Les données concernent les films Netflix. Le fichier films.csv est à télécharger depuis l’espace Elearn.

Ce fichier contient les variables suivantes :

  • id_oeuvre : identifiant du film
  • titre : titre du film
  • pays : pays
  • année_sortie : année de sortie
  • genre : genre de film
  • langue : langue du film
  • notemoyenne : note moyenne sur 10
  • budget : budget du film
  • recettes : recettes du film

Ces données ont été extraites du jeu de données netflix_movies_detailed_up_to_2025.csv (voir la source - Dernier accès le 06 oct. 2025).

Créez un projet RStudio et organisez votre script et vos fichiers de données de manière à ce que le projet soit reproductible.

Le projet RStudio doit comporter au minimum

  • un dossier pour stocker les scripts R (ou d’un autre format, Rmarkdown ou quarto par exemple) utiles pour le travail, que l’on peut nommer scripts
  • un dossier qui contient les données source et/ou produites, que l’on peut nommer data
  • un dossier où sont stockés les graphiques créés au cours de l’analyse, que l’on peut nommer plots

Indiquer en 2 points en quoi un projet RStudio est utile pour la reproductibilité d’une analyse*

Un projet RStudio est particulièrement utile pour la reproductibilité d’une analyse car il permet :

  1. de centraliser tous les éléments associés à un projet (scripts, données, documentation, graphiques), ce qui garantit que l’analyse peut être reproduite à l’identique ultérieurement ou par d’autres personnes et sur différents environnements

  2. d’automatiser l’organisation du travail avec une gestion facilitée des chemins d’accès et du répertoire de travail

#   ____________________________________________________________________________
#   Chargement des packages                                                 ####
library(tidyverse)

#   ____________________________________________________________________________
#   Immport des données                                                     ####
readr::read_csv2("data/films.csv") -> films

#   ____________________________________________________________________________
#   Correction du nom des variables                                       ####
films |> 
  rename(annee_sortie = année_sortie,
         note_moyenne = notemoyenne) -> films 

#   ____________________________________________________________________________
#   Création de la variable "profit"                                        ####
films |> 
  mutate(profit = recettes - budget) -> films

La commande films |> rename(annee_sortie = année_sortie, note_moyenne = notemoyenne) permet de renommer

  • “année_sortie” en “annee_sortie” pour enlever les accents qui peuvent poser problème
  • “notemoyenne” en “note_moyenne” pour garder une certaine cohérence dans le nom des variables, qui sont écrites en suivant la convention de nommage underscore_separated, qui écrit les noms de variables en minuscules avec les mots séparés par un underscore (_)

Qu’est-ce-que le tidyverse ? Citez 3 packages qui en font partie.

Le tidyverse est un ensemble de packages R conçus principalement par Hadley Wickham, pour la science des données. Ces packages partagent une philosophie commune, une syntaxe uniforme et des formats de données compatibles, afin de rendre la manipulation, la transformation et la visualisation des données plus intuitives, efficaces et reproductibles. Dans le tidyverse, les données sont organisées de manière “propre” (tidy) de sorte que dans le jeu de données chaque variable = une colonne et chaque observation = une ligne.

Les neuf packages principaux du tidyverse, qui sont chargés lors de l’exécution de la commande library(tidyverse) sont les suivants :

  • dplyr pour la manipulation de données (filtrage, sélection, regroupement)

  • ggplot2 pour la visualisation graphique

  • tidyr pour la mise en forme des données

  • readr pour l’import/export de données

  • tibble pour un format de tableau de données amélioré

  • purrr pour la programmation

  • stringr pour la gestion des chaînes de caractères

  • forcats pour les variables catégorielles

  • lubridate pour la manipulation des dates et heures

Ces packages peuvent bien entendu être chargés individuellement avec la commande library(_nomdupackage_)

Décrivez le rôle de chacune des couches que vous utilisez dans ce graphique

  • La fonction ggplot() sert à initialiser le graphique. Le jeu de données à utiliser est précisé comme paramètre de la fonction

  • La couche aes() permet de préciser les variables que l’on souhaite représenter sur le graphique. Ici sur l’axe des abscisses, on positionne le genre de films et sur l’axe des ordonnées, on positionne les notes

  • La couche qui suit, geom_boxplot() indique le type de graphique souhaité. Ici, une boxplot

  • Les couches qui sont ajoutées par la suite ne sont pas obligatoires, contrairement aux précédentes. Elles sont ajoutées pour améliorer la mise en forme du graphique et faciliter sa lecture

    • scale_fill_manual() définit manuellement la palette couleur utilisée

    • labs() sert à ajouter les étiquettes au graphique : titre principal, de l’axe des abscisses et de l’axe des ordonnées

    • coord_flip() effectue une rotation du graphique, ce qui permet une meilleure lisibilité des étiquettes de l’axe des abscisses

Informations complémentaires

  • On aurait pu inverser x et y et ne pas utiliser coord_flip()

  • On pourrait supprimer la légende qui n’apporte pas d’information complémentaire, en ajoutant la commande theme(legend.position = "none")

  • Montrez l’évolution du nombre de films par année, en utilisant une courbe
  • La courbe ainsi que les libellés des axes seront de couleur bleue

# Préparation des données : calcul du nombre de sorties par année avec count()
films |> 
  dplyr::count(annee_sortie) |> # le résultat est dans une variable nommée "n"
# Graphique
  ggplot() + 
  aes(x = annee_sortie, y = n) + 
  geom_line(color = "#0072BB") +
  labs(title = "Nombre de sorties de films entre 2010 et 2025",
       x = "Année",
       y = "Sorties") +
  theme(axis.title.x = element_text(color = "#0072BB"),
        axis.title.y = element_text(color = "#0072BB"))
# Export du graphique
ggsave(file = "plots/SortiesParAn.png")

  • Sélectionnez les films de la France et des États-Unis
  • Comparez la note moyenne par genre et pays, en utilisant un diagramme en barres, avec une facette et une couleur pour chacun de ces 2 pays
  • Faites les ajustements nécessaires pour que le graphique soit lisible et compréhensible
# Préparation des données : calcul de la note moyenne par genre et pays
films |> 
    filter(pays %in% c("France", "United States of America")) |>
    group_by(genre, pays) |> 
    summarise(note_genre_pays = mean(note_moyenne, na.rm = TRUE)) |> 
# Graphique
  ggplot() + 
    aes(x = genre, y = note_genre_pays, fill = pays) + 
    geom_bar(stat = "identity") + 
    scale_y_continuous(limits = c(0, 10),
                       # graduations tous les 1
                       breaks = seq(from = 0, to = 10, by = 1)) +
    coord_flip() + 
    facet_grid(rows = vars(pays)) + 
    labs(title = "Note moyenne par genre pour la France et les USA",
         x = "Genre",
         y = "Note moyenne") +
    theme(legend.position = "none")

Dans un premier temps, il faut calculer la note moyenne par genre pour la France et les USA. On va donc grouper les données sur ces 2 variables, avant de calculer la note moyenne, que l’on va appeler “note_genre_pays”.

films |> 
    filter(pays %in% c("France", "United States of America")) |>
    group_by(genre, pays) |> 
    summarise(note_genre_pays = mean(note_moyenne, na.rm = TRUE))

# On aurait pu sélectionner les pays en écrivant
films |> 
    filter(pays == "France" | pays == "United States of America")

C’est ce nouveau tableau de données qui sert de base pour le graphique.

  • Dans la couche aes(), on positionne le genre sur l’axe des abscisses et la note sur l’axe des ordonnées. Le paramètre fill = pays, permet de donner une couleur différente aux barres selon le pays

  • Pour faire un diagramme en barres, on utilise geom_bar(). Le paramètre stat = "identity" doit être mentionné pour bien prendre en compte la variable y précisée à la ligne précédente dans aes()

  • L’échelle des notes allant de 0 à 10, on peut fixer les limites de l’axe des ordonnées à 0 (min) et 10 (max) avec scale_y_continuous(limits = c(0, 10))

  • Pour améliorer la lisibilité, on fait une rotation du graphique avec coord_flip()

  • Pour avoir une facette par pays, on utilise la fonction facet_grid(). Pour une meilleure lisibilité, on positionne les facettes l’une sous l’autre, avec le paramètre rows : facet_grid(rows = vars(pays))

  • La commande theme(legend.position = "none") supprime la légende

Une solution alternative, avec une sélection automatique des 3 genres principaux

# Préparation des données - étape 1
films |>
  # sélection des budgets et recettes positifs (>0) 
  filter(budget > 0 & recettes > 0) |> 
  # calcul du nombre de films selon le genre
  group_by(genre) |>
  count() |> 
  # annuler la structuration selon les groupes
  ungroup() |> 
  # tri des genres par ordre décroissant des effectifs
  arrange(desc(n)) |> 
  # conservation des 3 premières lignes
  slice(1:3) |> 
  # sélection de la variable "Genre" et enregistrement du résultat dans genres_top3
  pull(genre) -> genres_top3
